隐私政策

更新日期：2026 年 11 月 3 日 · 开发者／运营者：Mu

你的照片由你掌控。FrameFilm 的照片编辑与胶片渲染在设备上完成。

政策概要

本政策适用于 FrameFilm（部分界面显示为“映格”或 FrameTone）的 Android、iOS 和 HarmonyOS 版本及本支持网站。当前应用无需注册账号，不提供开发者运营的照片云端存储；不主动将导入照片、编辑记录上传到开发者服务器，未集成广告、用户行为统计或第三方自动崩溃上报服务。

1. 在设备上处理的数据

  • 照片与 RAW 文件：仅在你选择导入后读取相关文件，并在应用存储空间保存副本，用于预览、编辑和导出。
  • 照片元数据：可能读取文件名、尺寸、相机／镜头型号、拍摄时间和曝光参数等，用于显示信息和处理照片。原文件本身可能含有位置等 EXIF 信息。
  • 编辑记录及缓存：在本地保存素材信息、调节参数、历史记录、缩略图及预览缓存，以便继续编辑、撤销和提高预览效率。

这些处理不等于向开发者传输数据。应用不会为了核心编辑功能要求你提供姓名、电话号码或账号资料。

2. 权限与用户选择

  • 照片／文件选择：通过系统选择器读取你主动选择的素材。来自云盘或系统云相册的文件，可能由相应系统或文件提供方下载。
  • 保存照片：导出时通过系统相册或文件接口保存结果；iOS 会申请向照片图库添加照片的权限。部分旧版 Android 系统需要存储写入权限。
  • 触觉反馈：部分平台使用振动权限提供操作反馈。

你可以在系统设置中管理适用的权限。拒绝相关权限可能使对应的导入或保存功能不可用，不影响已有本地素材的其他可用操作。

3. 导出与位置信息

导出设置可按版本提供保留拍摄信息（EXIF）和保留位置的选项。开启后，源照片中存在的相应元数据可能写入导出文件。应用无需获取设备当前位置来复制源文件已有的位置数据。

分享照片前，请检查导出设置；不希望暴露拍摄地点时关闭保留位置选项。导出或分享后的照片由你选择的相册、文件服务或接收方管理。

4. 联网、第三方与本网站

当前核心编辑流程不依赖开发者服务器，不出售照片或个人信息，也不将其用于广告投放。LibRaw、SpektraLab 等处理组件在设备上执行，不是照片上传服务。

应用商店支付、系统备份、云相册、文件提供方和系统诊断由对应平台按其政策处理。系统或应用商店可能按你的设置提供诊断信息，不能将其与应用自行集成的上报服务混为一谈。

这两个网页不加载第三方分析脚本、广告或外部字体，也不主动设置追踪 Cookie。若通过 GitHub Pages 托管，GitHub 会按其政策处理访问网站时的技术信息，例如 IP 地址和请求日志。详见 GitHub 隐私声明。

5. 主动联系与问题反馈

你发送邮件时，我们会接收邮箱地址、邮件内容及你主动提供的截图、照片或诊断信息，并仅将其用于回复、排查和处理你的请求。邮件服务提供方也会按自身规则处理邮件。

反馈无需提供原始照片；如需协助分析特定 RAW 文件，我们会与你沟通所需样本。发送前请移除不必要的个人信息，勿发送账号密码、验证码或签名私钥。

反馈资料仅在处理问题及必要后续沟通期间保留；不再需要时删除或匿名化，法律另有要求的除外。你可以通过下方邮箱提出查询、更正或删除请求。

6. 保存期限与删除

  • 导入副本及编辑历史会保存在本地，直至你删除相关记录或清除应用数据。
  • 在首页历史记录的“管理”入口删除素材，会删除对应编辑记录、应用内原文件及预览；不会删除系统相册中的原图或已导出的照片。
  • 缓存／空间管理可清理可重建的缓存；清缓存与删除素材不是同一操作，请以确认界面的说明为准。
  • 删除应用或通过系统清除应用数据通常会移除本地应用数据。iOS 的“卸载 App”可能保留文稿与数据，需使用“删除 App”才能一并移除。
  • 已经导出的照片、发送的反馈以及系统／云端备份不会因删除应用而自动移除，需在相应服务中另行管理。

7. 安全与未成年人

应用利用系统提供的应用存储隔离和权限机制保护本地数据。请妥善保管设备，并在删除素材前保存需要保留的结果。任何存储或传输方式都无法保证绝对安全。

未成年人应在监护人指导下使用应用及提交反馈。如监护人认为反馈中包含不应保留的未成年人个人信息，可联系我们处理。

8. 政策更新与联系

功能或数据处理方式发生变化时，我们会更新本页面及日期；需要另行告知或取得同意的事项，将按适用要求处理。
